# agy-skills

Conjunto de 76 skills usadas no Antigravity (`agy`) e no Claude Code: Django e Python, front-end e design,
marketing e SEO, privacidade, Git e trabalho em equipe.

## Por que isto existe
As skills do Antigravity e do Claude Code ficam em pastas locais de cada computador
(`~/.gemini/config/skills` e `~/.claude/skills`). Elas não acompanham a conta, então em cada PC é preciso instalar.

## Instalar em um PC novo
```bash
git clone git@github.com:Zackzinzz07/agy-skills.git
cd agy-skills
./install.sh          # Antigravity e Claude Code
```
Para atualizar depois: `git pull` (os links já apontam para esta pasta).

## Observações
- Cada skill vem de uma biblioteca de terceiros e mantém a licença original dentro da sua pasta.
- Não coloque chaves de API aqui. O repositório é privado, mas não deve ter segredos.
